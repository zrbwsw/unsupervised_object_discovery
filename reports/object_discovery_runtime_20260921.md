VOC12 图片数是 VOC07 的 **2.303 倍**，平均 patch 数几乎相同；同方法 DINO 的端到端实测约 **2.415 倍**。剩余差异可能来自读取、初始化及共享机器负载；当前数据未分项计时，不能进一步归因。

COCO20K 图片数是 VOC12 的 **1.717 倍**，平均 patch 数还增加到 **1.491 倍**。当前保留原分辨率，图邻接矩阵大小为 N×N；`object_discovery.py` 将其移到 CPU 后使用 `scipy.linalg.eigh` 做稠密广义特征分解。COCO 每图平均 N²、N³ 分别约为 VOC12 的 **2.27 倍、3.50 倍**，这仅说明潜在计算量上升，不是实测耗时倍率。实际时间还取决于 encoder、CPU 特征分解、图片读取的占比及并发负载。

VOC 的尺寸来自已完成的 DINO τ=0.10 `predictions.jsonl`；COCO 的尺寸来自固定 19,817 张子集的标注元数据。只读取已有文件，未运行新的评测。
